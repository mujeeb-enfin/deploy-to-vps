## Engineering rules

- **Language**: Match the existing project language. Check nearby files before adding new ones.
- **Icons**: No icon format restriction — use whatever fits.
- **DOM IDs**: Add IDs to interactive elements for testing. Not required on every element.
- **Re-renders**: Optimise hot paths for re-renders. Don't over-memo cold code.
- **Modules**: Group related code into modules. Shared utilities allowed.
- **Async**: No `setInterval`, no `setTimeout` for polling. Everything is event-driven: event bus, WebSocket push, AbortController, etc.
- **Logging**: `console.error` / `console.log` is acceptable. Don't swallow errors silently.
- **E2E policy**: No testing convention specified.
- **Verification**: Always run a production build to verify changes. Never ship on dev-only checks.
